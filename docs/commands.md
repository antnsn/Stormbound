# Commands

Everything in Stormbound can be set in the options window (`/storm`). These chat commands are shortcuts.

`/stormbound` works everywhere `/storm` does. Commands only do something on a shaman.

## Windows

| Command | What it does |
| --- | --- |
| `/storm` | Opens or closes the options window. `/storm options` and `/storm config` do the same. |
| `/storm help` | Lists the commands in chat. |
| `/storm ignore Debuff Name` | Adds a debuff to the [cure](features/cure.html) ignore list, or removes it if it's already there. Not case sensitive. |
| `/storm ignore` | Lists the ignored debuffs. |

## Frames

| Command | What it does |
| --- | --- |
| `/storm unlock` | Unlocks all frames so you can drag and resize them. See [Frames and minimap](features/frames-and-minimap.html). |
| `/storm lock` | Locks the frames again. |
| `/storm move` | Unlocks the frames, or locks them if they are unlocked. |
| `/storm reset` | Puts every frame back in its default place and size. |
| `/storm grid` | Turns snapping to the grid on or off. |
| `/storm grid 30` | Sets the grid size (4 to 100) and turns snapping on. |
| `/storm minimap` | Shows or hides the minimap button. |

## Tooltips

| Command | What it does |
| --- | --- |
| `/storm explain` | Turns the [explanations](features/explanations.html) in tooltips on or off. |

Every command also works without the space, for chat setups that swallow Enter after a space: `/stormunlock`, `/stormreset`, `/stormhelp` and so on.

Type anything else after `/storm` to get the list of commands in chat.

The [buff key](features/buff-key.html) is not a command: set it on the **Extras** page of `/storm`.
