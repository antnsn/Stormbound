# Camp Benefits

Sit or craft by a campfire for a minute and you get **Camp Benefits**: one buff with a bonus for each camp feature around the fire. A Camp Chair gives crit, a First Aid Kit Stamina, a Mana Well mana, and so on. It lasts an hour.

## What it does

- **Before it runs out.** A card counts down the last minutes and plays a sound, like Well-Rested and Well Fed. When it's gone, chat says so.
- **What the campfire lacks.** When you get a new Camp Benefits, chat names the features you ticked that it doesn't have, for example `Camp Benefits without: Camp Tent, Mana Well.` Then you know what to ask for, or which feature to put down yourself. It says this once per campfire, out of combat.
- **Upgrades count.** An upgraded feature counts as the basic one: a Greenhouse is an Incense Candle, an Anvil a Sharpening Wheel.

## The features

| Feature | Profession | Bonus |
| --- | --- | --- |
| Camp Tent | Leatherworking | Rested experience |
| Camp Chair | Skinning | Critical strike |
| First Aid Kit | First Aid | Stamina |
| Fish Bowl | Fishing | All stats, in % |
| Incense Candle | Herbalism | Intellect |
| Mana Well | Alchemy | Mana every 5 seconds |
| Sharpening Wheel | Blacksmithing | Strength |
| Lodestone | Mining | Attack power |
| Enchanted Lute | Enchanting | Armor, all stats, resistances |
| Faction Banner | Tailoring | Spirit |

Ticked from the start: Camp Tent, Camp Chair, First Aid Kit, Fish Bowl, and what your class gains from.

## How to use it

1. Type `/storm` and open the **Camp** page.
2. Tick the features you want; untick the ones you don't care about.
3. Sit by a campfire. Chat tells you what's missing.

## Settings

In `/storm`, page **Camp**:

| Setting | Default | What it does |
| --- | --- | --- |
| Warn, Sound, Countdown card, Rebuff warning | On, on, on, off | The same as for Well-Rested and Well Fed. **Test** shows the warning. |
| Warn with time left | 3 min | |
| In chat: which of these the campfire lacks | On | The chat line. |
| One switch per feature | Your class's | Which features you want. |

## Good to know

**A bonus doesn't stack with the class buff it matches.** First Aid Kit and Power Word: Fortitude, Fish Bowl and Blessing of Kings, Incense Candle and Arcane Intellect, and so on: you get the bigger one.

**The chat line names nothing.** Then the campfire had everything you ticked.
